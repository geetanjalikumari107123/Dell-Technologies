Dell Technologies Product Showcase

A modern and interactive Dell Technologies-inspired product showcase website built using React.js. The project features a premium dark-themed UI, animated product sections, feature carousel, product transitions, and responsive design.

Features

Modern Dell-inspired UI design
Interactive feature carousel
Automatic slide transitions
Product showcase with scroll-based transitions
Animated product images and content
Custom product information and pricing
QR code section
Responsive design for desktop, tablet, and mobile
Smooth CSS animations and transitions
Clean and reusable React components
Technologies Used
React.js
JavaScript (ES6+)
CSS3
HTML5
Lucide React Icons
